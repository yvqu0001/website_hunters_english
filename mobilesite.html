Mobilesite

Basic web

Under the theme “Basic Web”, work was carried out on the fundamental building blocks of multimedia design, which form the foundation for the subsequent themes. HTML pages and CSS files were set up from scratch, and the website was designed based on a provided wireframe, layout diagram, and content. During the work on this theme, basic HTML and CSS were introduced, with a particular focus on the use of CSS Grid and a small amount of Flexbox for layout structure.

In addition, basic design principles were applied in the development of the website. The text and the majority of the images were provided, but for the page “My Computer”, a self-taken image was used, which was optimized and converted to the WebP format. For visual inspiration, technology companies such as Apple, Samsung, and Microsoft were examined, as the provided content focused on an informational website about computers.

Design

Based on the findings from the desk research, which included an analysis of design solutions from Apple, Samsung, and Microsoft, a simple and cohesive color palette was developed consisting of dark gray, gray, light blue, white, and red.

Guided by value words such as “cool,” “tech,” and “clean,” a dark mode–inspired design was chosen, in which blue functions as the primary accent color and red is used for hover interactions.

Typographically, the font “Tomorrow” was selected for headings to support a sharp and technological expression, while “Helvetica Neue” is used for body text to ensure a clean layout and good readability.

Grid

In this theme, CSS Grid was introduced as the primary layout tool. Based on a hierarchical HTML structure and a mobile-first approach, the layout was initially built for smaller screens. Subsequently, multiple grid structures and selected Flexbox solutions were applied to adapt and further develop the layout for the desktop version of the website.

CSS Grid was used to create clarity and structure within the layout, while Flexbox was primarily applied for alignment and positioning of elements within individual sections.
